# Changelog: Brand

Each version is a git tag, `brand@<version>`, that matches `package.json`. The files themselves are published to `assets.servantium.com` whenever they change, at fingerprinted addresses that never change. A version marks a coherent state of the library and of `company.json`.

- **patch:** a corrected fact in `company.json`, or a re-exported file
- **minor:** new files in the library
- **major:** a change in the address scheme, or a file removed from use

## 0.1.0 (2026-09-29)

The asset library goes live at `assets.servantium.com`: 103 files, not indexed by search engines.

- **Logos:** the wordmark, symbol and S, as vectors from Figma's published Verdant library, with 2× PNGs. The wordmark is slate; "deep" tiles are forest.
- **Mascot:** all 12 of Astro's poses, as SVG and 240px PNG.
- **Icons:** favicons, the touch icon, and the website's 33 line icons.
- **Social cards:** the defaults for the website and the help center.
- **Email:** the banner art, the bookend strip and the LinkedIn icon.
- **Company facts:** `company.json`.

See [docs/asset-library.md](./docs/asset-library.md).
